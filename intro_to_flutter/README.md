## 📖 About the talk

Perfect for beginners and curious devs alike! This session takes you from zero to a working, interactive Flutter app.

## 🎯 What you'll learn

- 💡 Why Flutter and Dart are game changers
- 🧩 How Flutter's widget system works under the hood
- ⌨️ Live coding an interactive app from scratch
- 🌐 Handling APIs, layouts, and state like a pro
- 🧰 Insider tips, top packages, and tools to scale your app

## 💻 Demo app

The [`basic flutter app`](./basic%20flutter%20app) folder holds the app built live during the talk:

- **Stateless vs. stateful demo**: the classic counter, built both ways
- **Random joke generator**: fetches jokes from an API with the `http` package

```bash
cd "basic flutter app"
flutter pub get
flutter run
```

## ⚡ Flutter cheat sheet

```bash
# Create a project
flutter create .
flutter create --platforms=web,ios,android .

# Check your setup
flutter doctor

# Manage packages
flutter pub add <package>
flutter pub get
flutter pub upgrade
flutter pub outdated
```
